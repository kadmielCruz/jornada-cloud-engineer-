# Jornada para Cloud Engineer Jr.

## Sobre esta jornada

Sou profissional de TI com mais de 5 anos de experiência em Help Desk e Suporte Técnico N2. Estou direcionando minha carreira para Cloud Engineering, com foco inicial em Linux, redes, Git, Docker e AWS.

Este repositório documenta minha evolução prática, meus estudos, meus laboratórios e os projetos desenvolvidos durante essa transição.

## Objetivo

Desenvolver competências práticas para conquistar uma oportunidade como Cloud Engineer Júnior ou em uma posição inicial de Cloud Support / Cloud Operations.
